智能微信助手产品介绍

产品名称：智能微信助手（Skill + RAG 增强版）

核心架构：
本助手采用三层消息路由架构，确保响应既准确又高效。
第一层 Skill 层：通过关键词匹配触发确定性技能，包括天气查询和数学计算，命中后直接执行代码，不经过大模型，响应速度快且结果准确。
第二层 RAG 层：当 Skill 未命中时，系统检索本地知识库，将相关内容拼接到提示词中，再由大模型基于参考资料回答，避免幻觉和知识盲区。
第三层 LLM 兜底：前两层都未命中时，直接由大模型进行自由闲聊回复，处理日常对话和开放性问题。

技术栈：
后端框架：Spring Boot 4.x
大模型：火山方舟（字节跳动）
微信接入：iLink SDK
语音能力：百度语音识别与合成

RAG 对比测试说明：
开启 RAG 后，对于知识库中已有的问题（如功能介绍、使用说明、城市列表等），回答会基于知识库内容，准确且一致。
关闭 RAG 后，同类问题由大模型自由发挥，可能出现信息不准确或编造的情况。
建议在需要准确回答业务问题时保持 RAG 开启。
